Nothing to relearn, plenty to gain

If you've used IDM, you already know your way round DDM. Here's what stays, and what you get on top.

What stays the same

  • The toolbar, categories and download list, where you expect them.
  • The progress window with every connection, the queues, the Scheduler and Options.
  • The Download File Info window: the file starts while you choose where it goes.
  • The command-line switches: /d /p /f /a /n /s.

What you gain

  • Free, for good. No trial that runs out, no licence key, no ads. The GNU GPL keeps it free.
  • Faster where it counts. 1 GiB in 1.0 s against IDM's 5.5 s, and a small file in 0.03 s against 3.1 s, in our tests.
  • Torrents and magnet links in the same list. IDM's website doesn't mention BitTorrent.
  • {{LANGS}} languages built in, right to left too, and Linux and Mac versions.
  • Open source. Anyone can read the code and check what it does. No adware, no telemetry.

Move over in five minutes

  1. Export from IDMIn IDM, choose Tasks → Export → To IDM export file and save your list.
  2. Install DDMDownload it and keep Set up browser integration ticked.
  3. Import your listIn DDM, choose Tasks → Import → From IDM export file. Your downloads arrive with their addresses, referrers and cookies.
  4. Swap the extensionAdd DDM's extension to your browser (how) and turn IDM's off, so only one of them takes your downloads.

Questions

What is the best free alternative to IDM?
If you want Internet Download Manager's layout without its price, Dannex Download Manager: free and open source, laid out like IDM, and it imports your IDM list. If you need something else first, such as an Android app or a particular feature, the comparison above shows what each of the others is good at.
Is there an open-source IDM?
IDM itself is closed source. Dannex Download Manager is open source (GPL-3.0) and laid out the way IDM users expect, but it's a separate program written from scratch. Anyone can read its code on GitHub.
Is it related to IDM?
No. Dannex Download Manager is an independent project written from scratch in Rust. It has no connection to Tonec Inc. and contains none of IDM's code, artwork or text. Internet Download Manager and IDM are trademarks of their owner, named here only to compare. More
Is it really free, or a trial?
Really free, with no time limit, paid edition, ads or sign-up. More
Can I keep IDM installed too?
Yes. They don't share settings or files. Turn off one browser extension so each download goes to one program.
Does it work on Mac and Linux?
Yes: every release has a Linux version (AppImage, .deb, .rpm) and a Mac version for Apple Silicon and Intel, which is still experimental. More
