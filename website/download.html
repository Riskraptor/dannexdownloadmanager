On Linux or a Mac

Linux: the .deb and .rpm bring what DDM needs. DDM connects itself to your browsers at each start; then add the extension from your browser's store. Checked on GNOME, KDE Plasma, Xfce and Cinnamon. More in the help.

macOS: open the .dmg and drag Dannex Download Manager to Applications, then right-click it and choose Open the first time. The Mac version is experimental: tell us what doesn't work.

What you need

  • Windows 10 or 11, 64-bit, and about 100 MB of disk space.
  • Linux on x86-64 with a desktop session, X11 or Wayland.
  • macOS 11 or later, on Apple Silicon or Intel (experimental).
  • For video pages, DDM downloads yt-dlp (and ffmpeg if you want merged qualities) the first time you need them.

Check your download

Every release lists the SHA-256 checksum of each file in SHA256SUMS.txt. On Windows, compare it with certutil -hashfile file SHA256; on macOS and Linux with shasum -a 256 file. The build logs are on GitHub.

Older versions and the source code

Every release, with its notes and files, is on GitHub Releases. The source code is at github.com/Riskraptor/dannexdownloadmanager under the GNU GPL, version 3; building it yourself takes one cargo build.
